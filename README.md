# The Meeting That Should Have Been One Line

One original one-liner about a meeting that should have been an email,
entered in the [make.fun bounty](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

## The line

> Forty-five minutes in, someone finally said it out loud: 'This meeting is just an email with catering.'

## Run it

```sh
python3 main.py            # writes entry.txt to /output
OUTPUT_DIR=/tmp/out python3 main.py
```

`main.py` is pure standard-library Python. It writes exactly one line
(103 characters, no trailing newline) to `entry.txt`, honouring
`OUTPUT_DIR`.
